# Midnight Festival Palette

To prevent saturated festival colors from clashing against pure #000000, ground them with rich midnight navy tones derived directly from the dark letters in the poster (#27477D and #233762):

Background Base (--bg-base): #0B101B (Deep midnight navy)

Surface / Cards (--bg-surface): #151E31 (Elevated dark navy-slate)

Surface Border (--border): rgba(255, 255, 255, 0.08) or #27477D

Text High-Emphasis (--text-primary): #F8FAFC

Text Medium-Emphasis (--text-secondary): #CBD5E1

Text Muted (--text-muted): #F2C9A1 (Warm parchment tone)
